# Publicar Academia Sistemas como sitio web

[Volver al repositorio](README.md)

GitHub Raw muestra HTML como texto; para ejecutar la edición interactiva se requiere GitHub Pages.

## Activación única

1. Abre [Settings → Pages](https://github.com/mangelmorenomoreno/academia-sistemas/settings/pages).
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona **main** y **/(root)**.
4. Pulsa **Save**.
5. Comprueba la publicación desde Actions o Settings → Pages.

URL prevista: [https://mangelmorenomoreno.github.io/academia-sistemas/](https://mangelmorenomoreno.github.io/academia-sistemas/).

El repositorio incluye `index.html` y `.nojekyll`. No necesita servidor, dependencias ni compilación. Los documentos y animaciones son públicos. No guardar datos personales.

## Mientras se publica

- [Lectura navegable en GitHub](modulos/01-electronica-basica/clases/001-materia-atomos-electrones/libro/01.md).
- [Ficha del HTML](modulos/01-electronica-basica/clases/001-materia-atomos-electrones/libro.html): usa **Download raw file** y abre el archivo guardado en tu navegador. No hagas clic en Raw para leerlo.
- [Biblioteca PDF](modulos/01-electronica-basica/clases/001-materia-atomos-electrones/descargas.md).

La activación de Pages no se realiza mediante un commit; requiere configurar el origen de publicación en GitHub. La URL prevista solo funcionará después del despliegue correcto.
