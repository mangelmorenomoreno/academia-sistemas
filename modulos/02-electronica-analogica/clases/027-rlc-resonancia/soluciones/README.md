# Solucionario razonado

## 1. ¿Qué ocurre con f0 si C se cuadruplica?

Se reduce a la mitad porque f0 es inversamente proporcional a √C.

Criterio: conclusión y explicación coherente, unidades si corresponde.

## 2. ¿Por qué VL y VC pueden cancelarse?

Sus fasores tienen direcciones opuestas, no se suman como magnitudes positivas.

Criterio: conclusión y explicación coherente, unidades si corresponde.

## 3. ¿Qué pasa al aumentar R?

El pico baja y el ancho de banda aumenta en el RLC serie ideal.

Criterio: conclusión y explicación coherente, unidades si corresponde.
