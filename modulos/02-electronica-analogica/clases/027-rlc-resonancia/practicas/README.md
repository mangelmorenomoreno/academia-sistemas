# Laboratorio virtual

> Todas las prácticas de esta edición son virtuales. Nunca conectar la red doméstica, abrir fuentes ni provocar cortos. Montajes físicos posteriores solo con supervisión y fuente aislada de baja tensión limitada.

1. Dibuja esquema y referencias; predice antes de simular.
2. Simula una fuente senoidal de 1 V RMS con R=100 Ω, L=10 mH, C=1 µF en serie. Barre 500–5000 Hz, registra corriente eficaz y fase. Repite R=200 Ω; compara pico y ancho de banda.
3. Registra condiciones, unidades y diferencias. Conserva una captura o tabla.
4. Explica la causa de cada diferencia.
