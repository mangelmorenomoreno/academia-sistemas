# Solucionario razonado

## 1. ¿Qué pasa al duplicar L?

τ se duplica y la corriente tarda más en crecer, pero I∞=V/R se conserva.

Criterio: conclusión y explicación coherente, unidades si corresponde.

## 2. ¿Por qué vL es grande al interrumpir corriente rápidamente?

Porque vL=L·di/dt; un cambio muy rápido exige tensión grande.

Criterio: conclusión y explicación coherente, unidades si corresponde.

## 3. ¿Dónde se almacena la energía?

En el campo magnético asociado a la corriente.
