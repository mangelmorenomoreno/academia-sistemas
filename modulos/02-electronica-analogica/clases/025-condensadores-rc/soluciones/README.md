# Solucionario razonado

## 1. ¿Qué cambia al duplicar R?

τ se duplica y la corriente inicial se reduce a la mitad. El voltaje final ideal y la energía final no cambian.

Criterio: conclusión y explicación coherente, unidades si corresponde.

## 2. ¿Por qué una ESR alta calienta un condensador con corriente alterna?

La ESR disipa I_rms²·ESR aunque la corriente media sea cero.

Criterio: conclusión y explicación coherente, unidades si corresponde.
